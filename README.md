# PC Info Collector
Script em PowerShell para coletar informações básicas de hardware (Placa-mãe e BIOS).

## Objetivo
Auxiliar técnicos de suporte a obter rapidamente o modelo da placa-mãe e versão da BIOS para diagnósticos e inventário.

## Como utilizar
1. Abra o PowerShell como Administrador.
2. Execute: `.\pc-info-collector.ps1`

## Exemplo de Saída
```text
Fabricante MB: ASUSTeK COMPUTER INC.
Modelo MB    : PRIME B450M-GAMING
Versão BIOS  : 3211
